# Kho nhạc nền

File nhạc trong thư mục này **không vào git** (mỗi máy tự chép; trên VM: `~/video-agents/assets/music/`).

Đặt tên file bắt đầu bằng nhóm tâm trạng, hệ thống tự chọn bài theo lời đọc của từng video:

| Tiền tố | Dùng cho | Gợi ý lọc trong YouTube Audio Library |
|---|---|---|
| `calm - Ten bai.mp3` | phần lớn chủ đề | Mood: Calm / Inspirational |
| `bright - Ten bai.mp3` | tăng trưởng, cuộc đua, kỷ lục | Mood: Bright / Happy |
| `serious - Ten bai.mp3` | tử vong, thiên tai, khủng hoảng | Mood: Dramatic / Sad (bài nhẹ) |

Chỉ dùng nhạc có giấy phép rõ (YouTube Audio Library, bộ lọc "Không yêu cầu ghi công"). Không dùng bài từ YouTube Music.
Âm lượng, số lần dùng mỗi tuần, giấy phép ghi vào kho chất liệu: mục `music` trong `config/channel.yaml`.
